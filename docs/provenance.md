# コードと実験の来歴

このリポジトリの履歴は提出用コードの整理から始まります。探索当時のGit履歴を再構成したものではありません。元コードとの対応は`evidence/source_manifest.json`に保存しています。

評価器はRobot-sim-runtimeの`0c45f63`にある`evaluate_lab30.py`を起点に、固定地形、足接触、姿勢、終了条件、動画出力を追加したものです。公開版では実験用の絶対パスを除き、ローカル資産管理を同梱し、checkpointの指定を必須にしました。地形、報酬、成功判定の数値は変更していません。学習メタデータに残っていた未使用の固定評価幅欄は、実際の評価条件と一致しないため削除しました。評価幅は評価コマンドと結果JSONで特定します。

公式不整地baselineはランダム初期化から学習しています。公開済みの歩行モデルの重みを開始点にしたものではありません。`train_baseline.py`は公式CLIの設定読み込みと学習器の呼び出しを、相対的な出力配置とUSD取得先に対応させた実行入口です。標準報酬の設定と公式設定の差分は`baseline_source_audit.json`で照合します。

公式設定で確認された互換差分は、地形材質のクラス名`PhysxRigidBodyMaterialCfg`から`RigidBodyMaterialCfg`への置換です。報酬係数の変更ではありません。公式タスク本体は同梱せず、`sim/uv.lock`で固定した依存として導入します。

公開版の`runs/`は新しい学習・評価出力先です。`stage3_manifest.json`と`stage4_manifest.json`のcheckpointハッシュは元の実験の重みを識別する証拠であり、再学習で同じハッシュになることは期待しません。

`jump_balance`などの条件名は探索時の名称です。名称だけをもって、4足の離地を伴うジャンプが獲得されたことを意味しません。幅の大きな溝を踏破することと、空中移動で溝を越えることは分けて評価します。
